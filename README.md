# 岡商店 勤怠管理システム

## 機能

- **従業員管理** - 従業員の追加・編集・削除（時給・有給日数設定）
- **勤怠打刻** - 出勤・休憩開始・休憩終了・退勤
- **月次勤怠確認** - 打刻一覧・総稼働時間・給与表示
- **有給休暇申請** - 従業員による有給申請と残日数確認（土日祝休み考慮）
- **管理者機能（パスワード保護）**
  - 打刻修正・追加
  - 有給申請の承認・却下
  - 全従業員の給与レポート
  - パスワード変更

## セットアップ

```bash
# 依存パッケージのインストール
npm run install:all

# 開発サーバー起動（ターミナル2つ使用）
npm run dev:backend   # バックエンド (port 3001)
npm run dev:frontend  # フロントエンド (port 5173)
```

## 技術スタック

- **フロントエンド**: React + TypeScript + Vite + Tailwind CSS
- **バックエンド**: Node.js + Express
- **データベース**: SQLite (better-sqlite3)
